# Nod

Mac 上有几个动作，系统自己做不了、或者做得很难受。Nod 就把这几件事补上：

| 你遇到的麻烦 | 本来只能 | 装完 Nod |
|---|---|---|
| 退出豆包、飞书、ChatGPT 桌面版 | ⌘Q 要死死按住两秒，松早了没反应 | **一按就走**，对所有 App（访达除外） |
| 想收起当前窗口 | 摸到标题栏点黄按钮，或者 ⌘M | **四指右滑**，或三指/四指按下去那一下 |
| 想还原刚最小化的那个窗口 | 去程序坞里一个个翻 | **四指左滑**，它自己回来 |
| 千牛里按 ⌘W | 毫无反应 | **直接关窗口**（只管千牛，其它 App 的 ⌘W 不动） |

**不用配置**：不装 BetterTouchTool、不写脚本、不记快捷键，给一次权限就能用。
**没有存在感**：无程序坞图标、无菜单栏图标，开机静默启动，装完只会感觉到“少按了几次”。

看设置：双击「应用程序」里的 Nod 图标；关窗口按 `⌘W` 或 `Esc`。

## 系统要求

- Apple Silicon（M 系列）Mac
- macOS 12 或更新

## 下载

最新版在这里：**[Releases](https://github.com/FANCGG/Nod/releases/latest)**

## 安装

1. 下载 `Nod-x.y.z.dmg`，双击打开，把 Nod 拖进「应用程序」
2. 首次打开如果提示「无法验证开发者」：右键点 Nod → 选「打开」
3. 按提示给权限，见下一节

## 权限（只做一次）

系统设置 › 隐私与安全 › **设备控制和数据访问**
→ 点「+」从「应用程序」里选 Nod → 打开开关

**装过旧版本、开关拨了没反应？** 选中列表里的 Nod，点「−」删掉，再点「+」加回来。
从 4.0.11 之前升上来的这次要做一遍，之后就永远不用了。

没有这项权限，Mac 不允许任何程序最小化别人的窗口，也不允许接管 ⌘Q。

## 系统设置里要配合的三项

Nod 会自己检查这三项，缺哪一项就在设置窗顶部列出来，点旁边的「打开」直接跳到那一项，改完自动消失。

1. **三指拖移**（无障碍 › 指针控制 › 触控板选项）
2. **调度中心 = 四指上扫**（触控板 › 更多手势）
3. **轻扫切换空间 = 关闭**（触控板 › 更多手势），不然会跟 Nod 抢手势

## 更新

打开设置窗，版本号旁边出现「升级到 x.y.z」和小红点就说明有新版本，点一下会自动下载、替换、重启。

## 说明

- 全部本地运行，不联网（只在检查更新时读一次版本信息）
- 用自签名证书签名，不是苹果开发者证书，所以首次安装需要右键打开
- 装完如果手势没反应，去权限列表把 Nod 删掉重新加一次
