# Nod 手势增强

Mac 触控板小工具，纯后台运行：没有菜单栏图标，也没有程序坞图标。

## 它做三件事

| 操作 | 效果 |
|---|---|
| 四指右滑 | 最小化当前窗口 |
| 四指左滑 | 把刚最小化的那个窗口恢复回来 |
| 多指按压 | 最小化当前窗口（触控板按下去那一下，可选 3 指 / 4 指） |
| 按一下 ⌘Q | 直接退出当前 App（不用长按，豆包、飞书这类都生效，快捷操作爽飞天） |

要看设置，双击「应用程序」里的 Nod 图标；关窗口按 `⌘W` 或 `Esc`。

## 系统要求

- Apple Silicon（M 系列）Mac
- macOS 12 或更新

## 下载

最新版在这里：**[Releases](https://github.com/FANCGG/nod-gestures/releases/latest)**

## 安装

1. 下载 `Nod-x.y.z.dmg`，双击打开，把 Nod 拖进「应用程序」
2. 首次打开如果提示「无法验证开发者」：右键点 Nod → 选「打开」
3. 按提示给权限，见下一节

## 权限（只做一次）

系统设置 › 隐私与安全 › **设备控制和数据访问**
→ 点「+」从「应用程序」里选 Nod → 打开开关

**装过旧版本、开关拨了没反应？** 选中列表里的 Nod，点「−」删掉，再点「+」加回来。
从 4.0.11 之前升上来的这次要做一遍，之后就永远不用了。

没有这项权限，Mac 不允许任何程序最小化别人的窗口，也不允许接管 ⌘Q。

## 三件建议一起改的系统设置

配合起来才好用：

1. 系统设置 › 无障碍 › 指针控制 › 触控板选项 → 勾「使用触控板进行拖移」，选**三指拖移**
2. 系统设置 › 触控板 › 更多手势 › 调度中心 → 设成**四指向上轻扫**
3. 系统设置 › 触控板 › 更多手势 › 轻扫切换空间 → 选**关闭**

## 更新

打开设置窗，版本号旁边出现「升级到 x.y.z」和小红点就说明有新版本，点一下会自动下载、替换、重启。

## 说明

- 全部本地运行，不联网（只在检查更新时读一次版本信息）
- 用自签名证书签名，不是苹果开发者证书，所以首次安装需要右键打开
- 装完如果手势没反应，去权限列表把 Nod 删掉重新加一次
